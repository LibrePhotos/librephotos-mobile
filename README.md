# 📦 librephotos-mobile (archived)

> **This repository has been merged into [LibrePhotos/librephotos](https://github.com/LibrePhotos/librephotos).**
>
> The React Native mobile client now lives at **[`apps/mobile/`](https://github.com/LibrePhotos/librephotos/tree/dev/apps/mobile)** in the monorepo.

## Where things moved

| You used to do… | Now do… |
|---|---|
| `git clone https://github.com/LibrePhotos/librephotos-mobile.git` | `git clone https://github.com/LibrePhotos/librephotos.git && cd librephotos/apps/mobile` |
| Download the latest APK from [releases](https://github.com/LibrePhotos/librephotos-mobile/releases) | Download from [LibrePhotos/librephotos releases (mobile only)](https://github.com/LibrePhotos/librephotos/releases?q=mobile%2F) |
| Open issues here | Open them on [LibrePhotos/librephotos](https://github.com/LibrePhotos/librephotos/issues) with the `mobile` label |

Full commit history is preserved under `apps/mobile/` in the monorepo. Mobile release tags are namespaced as `mobile/<tag>` (e.g. `mobile/v1.1.1`, `mobile/latest`). The signed APKs published as GitHub releases on this archive remain downloadable; new releases will be published on the monorepo only.

Background: [issue #534](https://github.com/LibrePhotos/librephotos/issues/534).
